군포 전 품목 우위
전체 12.0%p 격차(88.6% vs 76.6%). 분석한 15개 품목 모두에서 군포가 성수를 앞서며, 최소 격차 품목은 후드티·맨투맨(4.2%p).
성수 재킷·일반셔츠 최대 격차
재킷 21.5%p(66.2% vs 87.7%), 일반셔츠 21.8%p(68.5% vs 90.3%) 격차. 특히 중간~밝은 색상에서 성수가 50%대까지 붕괴.
패딩 × 중간색 최악 조합
컬러 밝기 중간(3~6) 패딩의 성공률은 전체 최저 33.3%. 성수의 중간색 패딩은 0건도 아니며, 실제 데이터 기반 최저치로 즉각 대응 필요.
컬러가 성공률을 최대 28%p 좌우
성수 기준 진한색(1~3) 90.4% vs 밝은색(6~8) 62.4% → 28%p 차이. 컬러 자체가 팩토리 격차만큼 성과를 결정짓는 변수.
정장재킷 벤치마킹 포인트
군포 97.0%, 성수 91.1%로 양 팩토리 모두 최고 성과. 특히 진한색에서 97%+ 달성. 정장재킷 작업 방식의 타 품목 적용 검토 권장.
군포는 컬러 밝기 영향 적음
군포는 진한색 94.5% → 화이트 81.8%로 12.7%p 차이인 반면, 성수는 같은 구간에서 21.9%p 하락. 밝은 색 대응 역량 차이가 핵심.
